# متابعة الفهرسة والظهور — hamlf.com

ملف عمل داخلي لقياس أثر صفحات `en-pages-1` وما بعدها. تُملأ الجداول يدويًا من Search Console وGA4 وأسئلة ChatGPT.

## القواعد

- لا تُعتبر الصفحة مفهرسة إلا إذا ظهرت في Search Console بحالة **Indexed** («تمت فهرسة الصفحة»).
- «Request indexing» مرة واحدة فقط لكل رابط. لا يُكرر الطلب؛ التكرار لا يسرّع الفهرسة.
- اكتب الأرقام كما تظهر في اللوحة، مع التاريخ ونطاق المدة (مثلًا: آخر 28 يومًا). لا تقارن أرقامًا بنطاقات مدة مختلفة.
- أي رقم لم يُقرأ فعلًا من اللوحة يُكتب `—` ولا يُقدَّر.
