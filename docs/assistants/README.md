# فريق المساعدين (Claude) — مؤسسة د. حسن عبد المنعم حسن

> تعريفات المساعدين (9) موجودة في `.claude/agents/`. كل ملف فيهم مساعد مستقل، ليه اختصاصه وحدوده.
> بيشتغلوا من Claude Code على الريبو ده. تقدر تشغّلهم بالاسم («خلّي content-writer يكتب مقال عن…»)،
> أو كمهام مجدولة (Scheduled tasks) بتشتغل لوحدها في مواعيد ثابتة.

## بروتوكول التسليم (Handoff)

كل تسليم بين مساعدين بيبقى **بطاقة شغل** في طابور مشترك. الطابور موجود في **Firestore جوه تطبيق hamlf**
(`offices/{office}/records/handoffs/items`). الإدارة بتشوفه وبتقرر من شاشة **«غرفة العمليات»** (`78-ops-room.html`)،
والمساعدين بيقروا ويكتبوا فيه عن طريق `https://hamlf.com/api/handoff.php`. التفاصيل في `docs/handoff-setup.md`.

**التوكن** بيتبعت في هيدر `X-Agent-Token`. **عمره ما يتكتب في الريبو ولا في الشات.**

| العملية | الطلب |
|---|---|
| البطاقات اللي جاية لي | `GET ?action=list&to=<اسمي>&status=new,doing` |
| اللي اتغيّر من آخر مرة (أوفر) | `GET ?action=list&since=<ISO>` |
| بطاقة جديدة | `POST ?action=create` بالبيانات `{by, to, type, title, ref, details, links, due, prio, needsApproval}` |
| بدأت فيها | `POST ?action=update` بالبيانات `{id, by, status: "doing"}` |
| سلّمتها لمساعد تاني | `POST ?action=update` بالبيانات `{id, by, to: "<المساعد>", note}` |
| خلّصتها | `POST ?action=update` بالبيانات `{id, by, status: "done", note}` |

- **`by` و`to`:** اسم ملف المساعد (زي `legal-counsel`)، و`to` ممكن تبقى `management`.
- **`type`:** `consult` أو `article` أو `publish` أو `appt` أو `expense` أو `report` أو `doc` أو `tech` أو `other`.
- **`prio`:** عاجل أو عالي أو عادي أو منخفض.
- **`due`:** `YYYY-MM-DD`.
- **`links`:** روابط `https` بس (Drive أو البوابة)، مش نسخ من المستندات.

**قواعد الطابور:**
- **البطاقة اللي `needsApproval: true` مايقدرش المساعد يقفلها «تمت».** لو حاول، بتتحوّل «بانتظار موافقة الإدارة» وبتروح للإدارة، والإدارة توافق أو ترفض من التطبيق. ولو اترفضت، بترجع للمساعد اللي بعتها، ومعاها السبب.
- **مفيش مسح.** ومفيش تعديل على بطاقة بانتظار الإدارة أو بطاقة تمت.
- **مفيش أسماء موكلين في `title`.** المرجع (`ref`) يبقى رقم ملف أو قضية.
- **حصة فيربيز المجانية محدودة.** استخدم `since` بدل ما تقرا الطابور كله كل مرة، وماتعملش لفّة طلبات.

## قواعد ثابتة لكل المساعدين (ماحدش يكسرها)

1. **الريبو ده عام (public).** ممنوع يدخله أي باسورد أو مفتاح أو توكن، ولا بيانات موكلين (أسماء أو أرقام أو قضايا أو مستندات).
   - الأسرار مكانها ملفات إعدادات على Hostinger «فوق» `public_html`، زي `opay-config.php`، أو GitHub Secrets.
   - بيانات الموكلين مكانها Firestore وDrive بس.
2. **ممنوع الـ push على `main`.** أي push على `main` بيتنشر على hamlf.com على طول (Hostinger). الشغل يتعمل على branch، ويتعمل Pull Request، والإدارة هي اللي تدمج.
3. **مفيش حاجة توصل للعميل أو للجمهور من غير موافقة الإدارة:** رد إيميل، أو رسالة واتساب، أو رد على تقييم، أو رأي قانوني، أو مقال منشور. المساعد بيجهّز مسودة، والإدارة بتعتمد.
4. **ممنوع إدخال باسوردات، أو إنشاء حسابات، أو تقديم إقرارات على بوابات حكومية.** المساعد يجهّز، والإنسان يقدّم.
5. **ممنوع اختراع أرقام طعون أو مبادئ نقض أو مواد قانون.** أي مرجع لازم يكون من مصدر موثّق، ويتكتب جنبه مصدره. ولو مش متأكد، يكتب «يحتاج تحقق».
6. **الرد على الإدارة بالعربي المصري.** المحتوى المنشور بالفصحى (عربي) أو إنجليزي رسمي.
