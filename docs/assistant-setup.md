# تشغيل «مساعد المكتب» — الإيميل (info@hamlf.com)

المساعد بيقرا الإيميلات اللى بتوصل على info@hamlf.com، ويجهّز لكل إيميل:
تصنيف + ملخص وترجمة عربى ليك + **مسودة رد بلغة المرسل** + ترجمة الرد عربى.
**عمره ما بيبعت لوحده** — بتراجع وتبعت من صفحة `hamlf.com/assistant/inbox.html`.
الاستشارات والمواعيد والشكاوى بتتحوّل كمان بطاقة فى «غرفة العمليات» (لو الطابور متشغّل).

> الريبو عام: مفتاح Claude وباسورد الإيميل بيتكتبوا فى ملف على Hostinger بس — عمرهم ما يدخلوا الريبو ولا الشات.

## ١) مفتاح Claude API
1. ادخل console.anthropic.com ← سجّل بإيميل المكتب ← **Billing** واشحن رصيد (٥–١٠ دولار يكفوا شهور فى البداية).
2. **API Keys ← Create Key** ← سمّيه `hamlf-email` ← انسخه (بيظهر مرة واحدة).

## ٢) باسورد صندوق info@hamlf.com
من hPanel ← **Emails** ← info@hamlf.com. لو مش فاكره اعمل **Change password** (وحدّثه بعدها على أى موبايل/برنامج بيستخدمه).

## ٣) رفع المكتبات (مرة واحدة)
1. نزّل `assistant-vendor.zip` (هبعتهولك فى الشات — مش فى الريبو).
2. hPanel ← **File Manager** ← افتح الفولدر **اللى فوق** `public_html` (اللى فيه `whatsapp-config.php`).
3. اعمل فولدر اسمه `assistant-lib` ← ارفع الـzip جوّاه ← **Extract**. لازم يبقى عندك:
   `assistant-lib/vendor/autoload.php`
4. خد المسار الكامل من File Manager (بيبقى شبه `/home/u123456789/assistant-lib/vendor/autoload.php`).

## ٤) ملف الإعدادات
1. فى نفس الفولدر اللى فوق `public_html` اعمل ملف جديد اسمه `assistant-config.php`.
2. انسخ فيه محتوى `api/assistant-config.example.php` من الريبو، واكتب:
   - `anthropic_api_key` ← المفتاح من خطوة ١.
   - `mail_password` ← باسورد info@hamlf.com.
   - `vendor_autoload` ← المسار من خطوة ٣.
   - `admin_password` ← كلمة سر طويلة لصفحة المراجعة (دى اللى هتدخل بيها).
   - `office_profile` ← كمّل مواعيد المكتب (والأسعار لو عايز المساعد يذكرها). أى معلومة مش هنا المساعد هيقول «المكتب هيأكد».
   - `handoff_token` ← نفس `agent_token` اللى فى `handoff-config.php` (أو سيبه فاضى لو غرفة العمليات لسه مش متشغّلة).
3. احفظ.

## ٥) التشغيل الدورى (Cron)
hPanel ← **Advanced ← Cron Jobs** ← **Custom**:
- الأمر: `php /home/u123456789/public_html/api/assistant.php poll` (غيّر الرقم لرقم حسابك)
- كل ١٠ دقايق: `*/10 * * * *`

**أول تشغيل بيبقى «نقطة بداية»:** المساعد مش هيقرا الإيميلات القديمة، هيبدأ من اللى هتوصل بعدها.

## ٦) الاستخدام
`hamlf.com/assistant/inbox.html` ← كلمة السر ← تبويب «⏳ مستنياك»:
- افتح الإيميل ← اقرا الترجمة والتحليل ← عدّل الرد مباشرة، أو اكتب تعديلك **بالعربى** فى «عدّل بالعربى وهو يترجم» ← **✓ إرسال**.
- الرد بيطلع من info@hamlf.com فى نفس سلسلة العميل، ونسخة منه بتتحفظ فى «المرسل».
- «↻ تحديث الآن» بيسحب البريد فوراً من غير ما تستنى الـCron.
- النشرات والرسايل الآلية بتتعلّم «آلى — من غير رد» ومابتتبعتش لـClaude.

## التكلفة
كل إيميل = نداء واحد لـClaude (وكل «عدّل» = نداء إضافى). بالموديل الافتراضى
`claude-opus-5-5` التكلفة فى حدود سنتات قليلة للإيميل العادى. لو عايز توفّر غيّر `model`
فى الإعدادات لـ`claude-sonnet-5-5` أو `claude-haiku-5-5`. المساعد بيقرا أول ٣٠ ألف حرف من الإيميل بس، وأقصى ١٠ إيميلات كل سحبة.

## لو حاجة مش شغالة
الصفحة بتقول السبب بالعربى:
| الرسالة | الحل |
|---|---|
| ملف الإعدادات مش موجود | الاسم لازم يبقى `assistant-config.php` فى الفولدر اللى فوق `public_html` |
| ملف الإعدادات ناقص | فيه قيمة لسه `PASTE_…` أو `CHANGE_ME…` |
| مكتبات المساعد مش مرفوعة | راجع مسار `vendor_autoload` |
| بريد المكتب رفض الطلب | باسورد info@hamlf.com غلط |
